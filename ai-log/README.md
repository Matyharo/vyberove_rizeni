# Záznam práce s AI

Práce probíhá v Codexu, který zadání připouští jako obdobný nástroj. Do této složky bude před odevzdáním vložen autentický export dostupný v použitém prostředí. Příkaz Claude Code `/export` není v tomto projektu tvrzen jako použitý.

Tento soubor není export konverzace. Zpětně vytvořené shrnutí nesmí být označeno za původní přepis. Před zveřejněním export zkontrolovat kvůli soukromým údajům; případné redakce výslovně označit.

První pokyn uživatele: výběr zadání A po poskytnutí původního zadání. První etapa: plán před sběrem dat, pilot VC s českou kanceláří, důkazy u každého údaje, měření přesnosti s lidskou kontrolou.
